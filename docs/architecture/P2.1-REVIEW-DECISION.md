# P2.1 Review Decision

Date: 2026-06-20
Decision: Accept with applied changes

## Accepted

- Canonical `snake_case` names with explicit unit suffixes.
- Human translation through per-field OpenStudio lineage metadata.
- Stable handles as canonical relationships and nullable names as labels.
- Deterministic construction-time sorting and canonical UTF-8 JSON.
- `InventoryArtifact` as an internal frozen dataclass.
- P2.1 scope limited to schemas and serialization.

## Applied Before Checkpoint

- Corrected the immutability guarantee: Pydantic freezing is shallow.
- Documented the `build once, serialize once` invariant for schema `0.1.x`.
- Added tests proving post-construction nested mutation changes the artifact hash.
- Added rejection tests for NaN and positive/negative infinity.
- Added deterministic UTF-8 Unicode coverage.
- Added strict unknown-field rejection coverage.

## Deferred

- Tuple-based deep immutability.
- Nullable `osm_label` for SDK-derived values.
- Runtime enforcement inside the P2.2 extractor.
- Relationship integrity checks against extracted collections.
- Verification of the provisional `space_local` coordinate frame.
- Generated complete human field-map documentation.
- Relocation of legacy `ProjectSpec` and `TaskStep` exports before `0.3.x` stabilizes.

## Gate For P2.2

P2.2 may begin only after the P2.1 checkpoint. Office Hub counts, relationship resolution, source hash preservation, and coordinate-frame verification remain pending and must not be claimed by P2.1.
